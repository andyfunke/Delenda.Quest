# Ava contextual language

The contextual language seam is a deterministic, read-only projection layered
onto OG Ava. It does not replace the compiler or create a second mutation
authority.

```text
visible GameState
  → disclosed projection + public revision
  → static catalog + current situation + authored evidence
  → normalized exact/longest match
  → existing ADVISE / REPORT / EXPLAIN instruction
  → existing request IR, cognitive Nexus, and renderer
```

Static aliases are finite and collision-checked. Authored references are
created only from visible current headline, briefing, question, standing-order,
and maneuver presentation text. Evidence carries its source section and an
excerpt capped at 280 characters. Missing text cannot create a reference.

Priority language uses `StrategicDimension` from the shared gate substrate. The
current objective uses the campaign substrate's existing problem target table.
Metrics and explanations use existing `CONCEPTS` calculations and visible
state values.

Mutation-leading phrases remain owned by the existing consequential grammar:
`stage advance`, `prepare gain territory`, and `issue advance` do not become
reads. Negated phrases such as `do not advance` clarify. A contextual binding is
validated at the request IR boundary and cannot carry an action or authority.
